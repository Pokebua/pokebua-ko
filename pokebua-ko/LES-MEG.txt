POKEBUA RIP & SHIP-KØ

1. Pakk ut ZIP-filen.
2. Åpne mappen "pokebua-ko" i Visual Studio Code.
3. Velg Terminal -> New Terminal.
4. Skriv: npm install
5. Når den er ferdig, skriv: npm start
6. Åpne:
   Admin:   http://localhost:3000/admin.html
   Overlay: http://localhost:3000/overlay.html

OBS:
1. Kilder -> + -> Nettleser
2. URL: http://localhost:3000/overlay.html
3. Bredde: 1920
4. Høyde: 1080

VIKTIG:
Terminalen må være åpen og "npm start" må kjøre mens du streamer.
Denne første versjonen lagrer køen bare mens programmet kjører.
